# 整段转向

选中需要调整的一段连续轨道，按住 Tab，再按想要的方向：

| 按键 | 目标方向 |
| --- | --- |
| Tab + D | 右 |
| Tab + A | 左 |
| Tab + W | 上 |
| Tab + S | 下 |

其他方向沿用游戏原版预设，支持反引号细分角度。目标方向以选区第一段非中旋轨道为准。

## 多选：直接调整原轨道

不用先剪切或复制。模组以选区前一块轨道为连接点，把整段轨道转向，并保留选区，方便继续调整。

- 选原方向：保持原样。
- 选反方向：只翻转前进方向。例如向左改向右时，上下位置保持。
- 选其他方向：整段一起旋转，保留原来的形状。

开启「保拍」时，反向镜像会调整旋转事件，保留段内节奏，并在接缝后恢复原本的旋转状态。两次旋转可以抵消且不改变判定时，只有其中至少一次是这次操作补出的，才会把它们一起去掉。配对需改动原有旋转时，只会改复制或选中的键型内的旋转。

Ctrl + Z 可以一次撤销方向修改和自动补偿。

### 保持原节奏

原地转向，或用 Tab + 方向键粘贴刚复制／剪切的轨道时，模组会对照原版计算的判定时间和实际按键次数。像 30° 伪双押这样的短间隔仍要按两次，不能用中旋把两次按键合在一起。剪切粘回原区间也会核对接出节拍。

先按所选方向转主体，再尝试只用角度和旋转接上。多个方案都能保拍时，优先保留原直线、避免陡折和重叠。如果还接不上，只在复制的键型里从接缝向后找最近的完整伪双押（没有时才考虑其他偶数押），先尝试理顺那一小段，必要时在组内补中旋。原地转向时，搜索范围是选区。如果双押就在开头，可以经过两次按键后再接上已经转向的主体，避免在第一押前折回上一格。中旋的自动回转不算作主体的方向。

「保拍」默认开启。关闭后仍可定向粘贴和转向，但不会因节奏改变而撤销操作，也不会自动补拍。下面的「自动排版优化 (测试)」和「允许变速保拍」会暂时隐藏，重新开启「保拍」后会沿用原来的设置。

「自动排版优化 (测试)」默认开启。只关掉这一项时，仍会核对原节奏，但不会重排接缝或自动加中旋。

### 模组怎样识别伪多押

原版「多次按键」是同一格的事件，伪多押是多个很接近但各有判定时间的按键。[7th Beat Games 的角度与时间换算](https://7thbeat.notion.site/Timing-Window-Calculations-a80645e4f14f487b9696a244e1727c57) 中，双星的 180° 对应一拍。没有统一的伪多押 BPM 分界；[玩家练习工具也按相邻按键间隔分组](https://adofai-rolling-practice.com/how-to-use)。

Angle 只在寻找中旋位置时使用这个经验规则：组内相邻判定不超过 75 毫秒、也不超过当地三分之一拍，组前后还要有明显更长的间隔。例如有效速度为 160 BPM 时，30° 相隔 62.5 毫秒，符合短间隔条件；是否属于一组还取决于前后节奏。原版「多次按键」事件和原有中旋照常保留，实际判定时间不使用这个阈值。

默认不添加「设置速度」事件，重排后会用原版重新核对判定时间。固定的首尾接缝如果仍无法保拍，模组会恢复操作并提示；可以扩大选区，或在 Angle 设置里开启「允许变速保拍」作为兜底。

## 单选：定向粘贴

只选择一个粘贴位置时，Tab + 方向键会将已复制或已保存的键型按目标方向粘贴。开启“覆盖”时沿用覆盖粘贴规则。

Ctrl + V 继续自动适配目标方向。单按 Tab 在松开时添加中旋。

## 单格事件复制

选中一格轨道后，在右侧点事件标签选中一个事件。Shift + 左键把范围加入选区，Ctrl + 左键单独加选或取消。点击 `1/2` 这样的页码可以直接选同类事件，列表和外部标签共用选区。列表中白色表示选中，灰色表示未选中。

Ctrl + C 复制选中的事件。Ctrl + V 将它们追加到目标轨道，保留原有事件。无法重复添加或共存的事件会跳过并提示。

多选时，普通左键先收起同类事件列表并保留选区。列表关闭后，再点一次取消多选。

## 重叠轨道切层

点击重叠处，谱面文件名下方会显示「1/3 · #2157」这样的层数与格号，以及使用原版贴图的左右三角按钮。点按钮可切换当前选中的轨道，并把它临时显示在最前面；右侧原版检查器会跟随切换。点到别处或开始试玩后，切层控件自动收起。切层只影响编辑视图，不会写入谱面。

## 旧格式

旧字母格式仍可使用；仅在不能表达所需角度时自动转换为数字角度格式，格式转换与本次操作一起进入撤销记录。

Ctrl + A 可在旧字母格式和数字角度格式中切换全谱角度显示。角度按原版轨道的入角、出角和旋转方向计算；只显示角度时不转换谱面。
